# Global Green Energy Report

This is a well revised and proven statistical report on the various sources of energy and how they affect the environment.

## Project Overview
this repository contains a well organized report that clearly shows how solar, wind and Geothermal energy are utilized in energy production.

# Features

* Header section: It contains the table of content with navigation links to various topics of the report.
* main section: This contains the executive summary for the for all the three energy sources explaining their scale, innovation and impact on the environment.It also contains the comparison data and the conclusion.
* Footer section: it contains the contact information, the email and the copyright  

## Getting Started

No build tools or dependencies required. This is a plain HTML project.

1. **Clone or download** the repository.
2. Ensure the `assets/` folder is in the same directory as `index.html`.
3. Open `index.html` in any modern web browser.

```bash
git clone https://github.com/JeromeJason-dev/GlobalGreen-Energy-report.git
cd GlobalGreen-Energy-report
open index.html
```
